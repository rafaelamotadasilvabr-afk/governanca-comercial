PROTÓTIPO GOVERNANÇA COMERCIAL

1. Abra index.html no navegador.
2. O protótipo funciona sem servidor.
3. Os registros criados ficam apenas no localStorage do navegador.
4. Isso é somente para validação do fluxo; não é a base definitiva.
5. Próxima fase recomendada: GitHub Pages -> Google Apps Script -> Google Sheets no Drive.

O arquivo appscript.gs é o esqueleto inicial do backend para a próxima etapa.
